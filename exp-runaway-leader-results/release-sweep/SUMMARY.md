# Reading of the numbers

*(Tables above are generated by the harness. This section is authored analysis over exactly those
numbers — no other data.)*

## 0. First: the PASS column does not discriminate in this run — do not read it as six failures

Every arm shows ❌, **including V0**. The single failing gate in all six cases is band-reach ≥70%:
searound's B2 sits at **69.5–70.8% across every arm, with V0 itself at 69.9%**. A baseline that fails
its own gate is not evidence about the arms; it is an under-powered gate. This is the known
methodology limit — a hard per-track ≥70% threshold on ONE N=100 run is a coin-flip for tracks whose
band sits near 70% (searound does), and pass/fail decisions are supposed to use pooled multi-seed
data (~300 races/track). So for this sweep the usable fairness signal is the **delta vs V0**, not the
PASS boolean. Every other binding gate (runaway, parade, action Δ, Holm) is met by R97/R95/R94-ON.

Holm is worth noting separately: it is **2/4 on every arm including V0, on the same two tracks**
(luger-hill and searound). No arm in this sweep moves it in either direction, so it carries no
information about the release point — it is a property of the baseline, not of the treatment.

## 1. The fairness cost — which metric degrades first, and how it scales

**bandExitAfterRelease degrades first, and it is monotone in the release point.** Pooled B1 exit:

| | V0 | R97-ON | R95-ON | R94-ON | R93-ON |
|---|---|---|---|---|---|
| B1 exit | 3.9% | 4.1% | 5.5% | 6.4% | 6.3% |
| B2 exit | 10.9% | 10.1% | 11.7% | 12.8% | 13.2% |

Both rows are monotone from R97 onwards. Moving release 0.97 → 0.94 **raises B1 drift by ~60%
relative** (3.9 → 6.4) and B2 by ~18% (10.9 → 12.8). The
per-track table shows it concentrates on **mountainstreet: 4.3% → 5.1% → 7.8% → 9.7% → 10.5%**, a
2.4× rise, monotone at every step. searound and dirt-oval each rise ~1.5×; luger-hill is flat.

This is precisely the diagnostic the metric was built for. Endpoint band-reach barely moves across
these arms (B1min 70.2 → 69.0) and would have suggested "no fairness cost". bandExitAfterRelease
shows the cost is real and is specifically **post-release drift** — racers who had already reached
their assigned band and then left it during the longer free run. That is the pack-release
endgame-drift signature, arriving as predicted, and it is the reason this metric was made
first-class rather than inferred afterwards.

## 2. Only then: the payoff — and there isn't one

**p1SwapAfter090 peaks at the DEFAULT release point and decays as release moves earlier:**

| | V0 | R97-ON | R95-ON | R94-ON | R93-ON |
|---|---|---|---|---|---|
| p1Swap | 25.5% | **34.3%** | 32.0% | 30.5% | 30.5% |
| ex-runaway swap | 0.0%† | **29.8%** | 27.7% | 28.7% | 30.9% |

†V0's ex-runaway swap is 0 **by construction, not by measurement**: a V0-runaway race is defined as
one whose 0.90 leader wins unchallenged, so a swap is impossible in that set. It is a tautology, not
a baseline — the meaningful comparison for that column is between the non-V0 arms.

R97-ON is the best or tied-best swap arm on **all four tracks** (27/43/28/39 vs V0's 24/28/27/23).
Every earlier release point is equal or worse. Lead changes tell the same story (1.51 at R97 → 1.45
at R93). Runaway suppression does not improve either — searound gets *worse* at R93 (14% → 17%), and
R93's overall 9.5% with a 17% max-track breaches the ≤15%/track gate that R97/R95/R94 clear.

**R94-OFF settles the attribution, and it is the sharpest result in the sweep.** Release moved earlier
with gap-reroll absent:

- runaway **23.3%** — statistically identical to V0's 23.5%; **89 of 94** V0-runaway seeds are *still*
  runaways.
- **0 of 94** ex-runaway seeds produced a late pass. Not a small number — zero.
- yet B1 exit still rises to **6.0%** vs V0's 3.9%.

So earlier release **alone** buys nothing at all — no runaway reduction, not one converted lonely
march — while already paying the full drift cost. The gap-reroll is doing 100% of the work: R97-ON
converts 63 of 94 runaways and produces 28 late passes in that same set.

## 3. Verdict against the binding rule

The spec's rule is that a release point which buys P1 fights but sells band fairness is not a
candidate. **No earlier release point is a candidate — and not because of the trade, but because
there is no trade.** R95/R94/R93 each cost monotonically more post-release drift than R97 and each
return *fewer* late passes; R93 additionally breaches the per-track runaway gate. R94-OFF shows the
release lever is pure cost when isolated.

The one arm that improves on V0 across the board — runaway 23.5% → 8.3%, p1Swap 25.5% → 34.3%,
action +0.32, drift essentially unchanged (3.9% → 4.1% B1, 10.9% → 10.1% B2) — is **R97-ON: the
already-confirmed gap-reroll candidate at the existing default release point, i.e. no release change
at all.**

## 4. What this implies for the eye-test complaint (owner's call)

The eye-test read was "chasers close in, but the 0.90 leader is almost never actually passed", and
the hypothesis under test was that the field runs out of runway. **The data does not support that
hypothesis.** Giving the field 3–4% more race as free run produced zero additional passes when
isolated (R94-OFF) and fewer passes when combined (R95/R94/R93 vs R97). Whatever is preventing the
final pass, it is not a shortage of runway — so this is the wrong lever, and the next hypothesis
should look elsewhere.

Worth noting against the felt experience: R97-ON already converts two thirds of former runaways and
lifts late passes to 34%. If the eye-test was run at a gap-reroll setting other than the confirmed
candidate — the 0.75 slider, for instance — that would be a different configuration from the one
measured here (see the small-G diagnostic: G=0.75 touches 3× more rolls for the same outcome).
Confirming which setting the eye-test actually ran at is cheap and would sharpen the next step.
