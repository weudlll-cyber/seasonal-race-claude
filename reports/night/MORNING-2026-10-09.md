## Piece E — the install branch (`feat/vps-install`, not merged)

- **`racearena harden-ssh`** — two phases, two sessions. `--user <name>` checks the user (not root, can use sudo, has a public key, `sshd_config` reads its drop-in folder), prints the plan and a one-time code; NOTHING changes. `--confirm <code>`, run through sudo from a SECOND session signed in as that user, finds that session's own SSH connection (sudo strips `SSH_CONNECTION`, so it is read from the nearest ancestor process) and requires sshd's "Accepted publickey" line for exactly that address and port. Only then is `00-racearena-hardening.conf` written; `sshd -t` and the effective settings (`sshd -T`) are checked and a failure removes the file again. Never run by `install.sh`, only printed as the next step.
- **fail2ban** — its own install step (so a re-run adds it to an existing server), jail in `deploy/fail2ban/racearena-sshd.local`: 5 tries in 10 minutes, 1 hour, read from the journal. `racearena status` shows it without failing on it.
- **`racearena uninstall [--purge-data]`** — a final backup first (nothing is removed if it fails), the domain typed to confirm; data and backups kept unless `--purge-data`, which asks a second time.
- **A5M-06** — the data and backup folders are owner-only at install and after a restore.
- **Caddy** adds HSTS and drops its Server banner (D1).

**Tested:** `deploy/test/hardening-check.sh` in a digest-pinned Debian 12 — fail2ban parses the jail and reads 5 / 10m / 1h, harden-ssh refuses root, no sudo, no key, no user and a confirmation without a plan, its dry run changes nothing, and `install.sh --dry-run` makes the folders owner-only and only prints harden-ssh: 19/19, sabotaged once (maxretry 6 caught). The end-to-end test on a local Docker, master `290e6db3` merged in: **62/62**.

**Found by the end-to-end test and fixed (`962c15e1`):** the uninstall's final backup runs in a one-off container that read standard input, and swallowed the typed confirmation — so a correct domain was refused, and the "wrong domain is refused" check had passed for the wrong reason.
